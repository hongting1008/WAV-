WAV 音效檔播放器 (WAV Audio Player)

專案簡介:
這是一個使用 Visual Studio 開發的 Windows 視窗應用程式，主要功能為讀取並播放 WAV 格式的音效檔。使用者可以透過直覺的圖形化介面操作音樂的播放、暫停與停止。

開發環境:Visual Studio 
程式語言:C++ / C# 

開發者:陳宏廷

執行說明:
1. 將專案 clone 到本地端，或下載解壓縮。
2. 使用 Visual Studio 開啟專案方案檔 (.sln)。
3. 點擊上方的「開始」或按下 F5 進行編譯與執行。
4. 點選介面上的「開啟檔案」按鈕，選擇電腦中的 .wav 音效檔即可開始播放。
